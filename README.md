# Cafe Sales Analytics Dashboard

## Project Overview
This project presents an interactive Cafe Sales Analytics Dashboard developed using Microsoft Power BI as part of Task 3 of my Data Analyst Internship at SWYNEX Technologies.

The dashboard helps analyze cafe sales performance, item-level revenue, quantity sold, monthly revenue trends, payment methods, and location-based revenue.

## Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- CSV Dataset
- Data Visualization and Exploratory Data Analysis

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Transactions
- Total Quantity Sold
- Average Transaction Value

## Dashboard Features
- Revenue by Item
- Quantity Sold by Item
- Monthly Revenue Trend
- Transactions by Payment Method
- Revenue by Location
- Interactive filters for Item, Payment Method, Location, and Transaction Date

## Key Insights
- Coffee was the top-selling item, with 3,534 units sold.
- Salad generated the highest item-level revenue of 17,320.
- Quantity and Total Spent showed a positive correlation of approximately 0.704.
- A total of 3,178 transactions had an Unknown payment method.
- Unknown location records limit reliable location-level analysis.

## Data Quality Note
The dataset contains Unknown values in payment method and location fields. These records are retained for transparency and should be considered when interpreting the results.
